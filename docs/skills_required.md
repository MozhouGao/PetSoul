# Skills & Knowledge Required

Technical skills needed to develop, maintain, and extend this project.

---

## Core Skills

### Python (Intermediate–Advanced)
- Dataclasses, type hints, async/await
- Virtual environments (venv/pyenv)
- Package management (pip, requirements.txt)
- Error handling patterns (try/except with logging)

### REST API Development
- FastAPI framework (routes, dependency injection, file uploads)
- HTTP methods, status codes, response types (JSON, file streams)
- CORS configuration
- Multipart form data handling

### Machine Learning / Computer Vision
- **Object Detection** — Understanding YOLOv8, bounding boxes, confidence thresholds, COCO class labels
- **Zero-Shot Classification** — CLIP model architecture, text-image similarity, prompt engineering for classification
- **Model Loading** — HuggingFace Transformers, PyTorch model loading, GPU/CPU device management
- **Image Preprocessing** — Resizing, cropping, RGB conversion, tensor normalization

### 3D Graphics
- 3D file formats (GLB/glTF, OBJ, PLY, STL)
- Mesh concepts (vertices, faces, polygons, textures, PBR materials)
- Coordinate systems and transformations
- Basic understanding of procedural mesh generation
